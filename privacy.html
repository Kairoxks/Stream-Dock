Stream Dock Privacy Policy

Effective date: October 28, 2026

Stream Dock is a personal-use integration that connects compatible keyboard or Stream Dock controls with Discord through Discord's OAuth2 authorization system.

Information Used

Stream Dock may use information provided through Discord authorization that is necessary to connect to Discord and perform features authorized by the user, such as Discord control actions.

Local Storage

The Stream Dock plugin stores the Discord Application ID and Discord authorization information locally on the user's device. The application is not intended to collect or maintain a separate remote database of Discord account information.

How Information Is Used

Authorization information is used only to provide the Discord integration and perform actions requested by the user through Stream Dock controls.

Sharing and Sale of Information

Stream Dock does not sell personal information. This personal-use application does not intentionally share Discord authorization information with advertisers or unrelated third parties. Information may still be processed by Discord as necessary to provide Discord services and API functionality.

Data Retention and Removal

Because the plugin stores its authorization information locally, users can stop using the integration, disconnect or revoke the application's Discord authorization, and remove locally stored application data to end the integration. Discord also provides controls for authorized applications within the user's Discord account settings.

Security

Users should never provide a Discord password, client secret, bot token, or account token to Stream Dock unless an official feature specifically requires it. The Stream Dock integration described by this policy is designed to use Discord OAuth2 authorization rather than a user's Discord password.

Changes

This Privacy Policy may be updated if the functionality or data practices of Stream Dock change.

Contact

Stream Dock is a personal-use application. Questions about this policy may be directed to the application owner through the method by which access to the application was provided.
